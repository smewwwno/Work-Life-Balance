# Core Principles

## Primary principles

- First define the core, then define the engine.
- One Telegram bot shell, not many separate bots.
- One routing layer, several internal domain roles.
- Everything deterministic belongs in Python.
- Everything interpretive belongs in the LLM layer.
- Category is mandatory for life-domain objects.
- Task means action.
- Event means presence in time.
- Goal groups tasks and events.
- Person is the primary object for relationships.
