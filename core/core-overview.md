# Core Overview

The system is designed as a **single Telegram bot shell** with internal domain roles.

## Principle

First define the core, then define the engine.

## Core layers

1. Concepts and principles.
2. Shared data objects.
3. Categories and labels.
4. Domain roles.
5. Routing rules.

## Primary scope

This repository initially focuses on the **Life** side of the broader Work-Life-Balance model.

## Roles in scope

- Router
- Body Coach
- Life Operations Manager
- Relationship Manager
- Leisure Curator
- Learning Coach

## Design pattern

Each role is stored as a markdown artifact with structured frontmatter and repeatable sections, inspired by agency-style agent catalogs.
